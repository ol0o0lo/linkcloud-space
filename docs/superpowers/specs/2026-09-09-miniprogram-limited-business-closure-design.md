# 小程序有限业务闭环设计

## 目标

在不引入 AI、电脑扫码登录、房东写入和高风险组织管理能力的前提下，补齐近期可上线的小程序业务闭环：邀请链接直达小程序、消息进入业务页面，以及组织端小区、楼栋和主动带看的最小写入能力。

## 范围边界

本期包含：

- 后端生成微信小程序 URL Link。
- 组织邀请与房东邀请共用统一小程序入口。
- 登录、手机号验证后返回邀请页，并由用户明确确认接受。
- 已知通知映射到小程序任务、公告、收益分配和订阅页面。
- 组织端新增和编辑小区、新增和编辑楼栋、主动创建带看。
- 房东端继续保持只读。

本期不包含：

- AI 功能。
- 小程序码登录电脑端。
- 小程序内创建组织。
- 房东端写入能力。
- 删除小区、删除楼栋、组织所有权转移等高风险操作。
- 任意外链 WebView 和完整跨端通知动作协议。

## 邀请与 URL Link

后端提供独立的小程序 URL Link 服务，复用现有微信小程序 access token 获取逻辑。服务接收目标页面、白名单业务参数和失效时间，调用微信 `generate_urllink` 接口并返回 URL Link。邀请链接统一进入 `pages/invitations/index`，查询参数只包含邀请类型和不透明凭证，不包含姓名、手机号、邮箱或组织名称。

组织邀请和房东邀请继续使用现有查询、接受接口。统一邀请页将两种响应适配为同一展示模型。未登录用户进入登录页后返回邀请页；需要验证手机号时进入手机号验证页并再次返回邀请页。登录或验证不会自动接受邀请，用户必须点击确认。

组织邀请接受成功后刷新工作空间，切换到受邀组织并进入首页。房东邀请接受成功后刷新房东关系，切换到返回的房东联系人并进入只读门户。如果业务关系已经建立但工作空间刷新失败，页面显示接受成功并只重试刷新，不重复提交接受请求。

URL Link 支持配置开关和 `develop`、`trial`、`release` 环境。开关启用后，微信接口失败必须使本次发送失败，不回退为管理端链接；测试环境关闭开关以避免真实微信请求。

## 通知业务跳转

小程序增加纯前端 `mobile-action-resolver`。解析器输入通知对象，输出内部路由、按钮文案和动作类型。解析顺序为：结构化 `data`、`category + target_type + target_id`、已知管理端 URL 白名单。未知相对路径不跳转。

首批映射：

- `team.task.*`：有 `assignment_id` 时进入本人任务详情，否则使用 `task_id` 进入组织任务详情。
- `team.announcement`：进入组织公告详情；已撤回公告不提供继续处理。
- `allocation.status`：进入收益分配申请详情。
- `subscription.billing`：进入组织订阅与订单页。

通知已过期、参数无效或无法识别时仅展示正文。HTTPS 外链在 H5 打开，在微信小程序中只复制链接，不新增 WebView。所有目标页面继续通过后端接口进行真实权限校验。

## 组织端写入

### 小区

小区列表增加新增入口，卡片进入共用的新建/编辑表单。必填字段为内部名称、展示名称、物业类型、省、市、区；可选字段为详细地址、开发商、建成年份和简介。本期表单不修改图片和地图坐标。编辑使用 PATCH，只提交表单负责的字段，不覆盖已有图片和坐标。保存后返回列表并刷新，不提供删除入口。

### 楼栋

楼栋列表增加新增入口，卡片进入共用的新建/编辑表单。必填字段为楼栋名称、总楼层和地址；可选字段为所属小区、地下楼层、建成年份、电梯和标签。允许创建独立楼栋。本期表单不修改图片和地图坐标。保存后返回列表并刷新，不提供删除入口。

### 主动带看

带看列表和组织房源详情增加创建入口。必填字段为房源、客户姓名、客户手机号和未来预约时间；可选字段为租客联系人、负责人和备注。从房源详情进入时预选房源。选择联系人后带入姓名和手机号，但允许修改本次记录。保存成功后进入带看详情，列表在返回时刷新。

本期沿用现有组织成员租赁资料维护规则，不新增细分 RBAC。后端始终从当前请求上下文获取组织，并校验关联资源均属于当前组织。

## 错误、安全与幂等

- URL Link 只能由后端生成，微信凭证不下发前端。
- 公开邀请详情和接受接口使用稳定业务错误码区分失效、对象不匹配、需要手机号验证和绑定冲突。
- 接受按钮和所有写入按钮使用单次提交锁。
- 组织邀请和房东邀请为成功接受写入短期幂等凭据，使相同用户重复提交同一 token 时返回原成功结果。
- 日志和埋点不得记录完整邀请 token、手机号或邮箱。
- 通知解析器只生成静态登记的小程序路由，所有 ID 必须为正整数。
- 表单遇到网络和服务错误时保留填写内容；401 进入登录，403 展示权限变化，404 展示资源失效，409 重新读取状态，字段错误定位到表单字段。

## 验收

- 微信聊天、短信或邮件中的 URL Link 可直接打开体验版或正式版的小程序邀请页。
- 登录和手机号验证后邀请上下文不丢失。
- 组织邀请和房东邀请成功后进入正确工作空间。
- 任务、公告、收益分配和订阅通知可以进入对应小程序页面；未知通知安全兜底。
- 小区、楼栋和带看三个写入流程能够创建、查看和继续后续业务。
- 房东端无新增写入口。
- 后端定向测试、小程序 lint、类型检查、Node 测试及 H5/微信构建通过。
