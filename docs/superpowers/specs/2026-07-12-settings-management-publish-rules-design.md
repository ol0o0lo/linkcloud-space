# 空间与团队设置的发布规则摘要优化

## 目标

降低发布规则设置页的无效信息密度，并让团队设置中的团队选择器成为清晰、紧凑的页面上下文。

## 范围

### 发布规则摘要

空间设置和团队设置继续复用 `PublishRulesControl`。摘要区仅渲染内容非空的规则状态：

- 有阻断项时显示红色“阻断发布”标签。
- 有提醒项时显示金色“仅提醒”标签。
- 有不校验项时显示默认“不校验”标签。
- 对应规则项为空时，不渲染其标签。

因此，当前默认规则只显示“阻断发布：房东主体、租金”；不显示“仅提醒：无”或媒体项的“不校验”摘要。规则表单和预设按钮保持不变。

### 团队选择区

移除团队设置页中仅包含团队下拉框的独立工具栏卡片。页面内容区前增加与空间设置一致的页面标题行：

- 左侧显示“团队设置”及简短说明。
- 右侧显示“当前团队”下拉框。
- 继续使用现有团队查询、默认选择首个团队、切换团队、加载态和设置数据刷新逻辑。

团队选择器是当前设置作用域，不新增保存操作、额外接口或持久化状态。

## 验收与测试

- 空间和团队设置页在空提醒或空不校验状态时不显示相应摘要标签。
- 有内容的状态摘要仍显示，且字段名称正确。
- 团队选择器位于团队设置标题区，不再以单独卡片出现。
- 切换团队仍按新团队 ID 获取设置；既有恢复默认和保存设置行为不变。
