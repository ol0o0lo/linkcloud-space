# 工作台切换器视觉调整设计

## 目标

将团队运营工作台页头右侧的工作台切换器改为更有识别度的图标按钮组，降低当前大面积灰底和厚重选中块带来的笨重感。

## 已确认方案

- 保留现有 `Segmented` 组件、两个选项、图标、权限判断、URL 参数和切换逻辑。
- 外层改为透明背景，两个选项之间保留 8px 间距。
- 每个选项使用独立圆角按钮外形；图标放入 30px 的圆角方块。
- 选中项使用浅蓝背景和蓝色细边框，图标使用蓝底白色；未选项保持透明，图标为浅灰底。
- 手机端保持两个选项等宽，保证文案完整和点击区域可用。
- 不修改多语言、依赖、生成代码及业务逻辑。

## 验证

- 对管理端运行 TypeScript / Biome 范围检查或项目 lint。
- 确认桌面端与窄屏媒体查询下样式规则完整。
