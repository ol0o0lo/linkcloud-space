# 小程序沉浸式身份切换设计

## 目标

将“我的”页导航栏左上角的身份切换从普通操作表升级为沉浸式工作空间面板，使当前身份更明确、多个身份更易浏览，同时保留现有切换数据流和页面跳转规则。

## 交互与视觉

- 点击导航栏身份入口后，从底部打开约占屏幕 70% 高度的面板。
- 遮罩层使用加深与背景模糊，让用户明确进入独立的身份选择场景。
- 面板顶部提供标题、辅助说明和关闭按钮。
- 当前身份使用品牌色英雄卡展示身份名称、用户名称、用途说明和“当前”状态。
- 其他身份使用纵向卡片列表展示，支持未来出现多个组织身份时自然扩展和滚动。
- 点击当前身份只关闭面板，不触发重复切换。
- 点击其他身份后，仅目标项显示加载状态，其他选项暂时禁用。
- 切换成功后关闭面板，并沿用现有逻辑进入该身份默认首页；失败时保留面板并显示错误提示。
- 面板使用柔和上滑和渐入动效；尊重 reduced-motion 偏好，不使用高幅度弹跳。

## 组件边界

- `AppModeSwitcher.vue` 继续负责入口展示、面板开关、身份选项渲染和切换调用。
- 使用 `wd-popup` 承载自定义面板内容，替换不适合复杂信息层级的 `wd-action-sheet`。
- 身份名称、描述、当前状态及切换目标继续来自 `appContextStore.modeOptions`，不新增业务状态源。
- “我的”页仅保留导航栏入口，不感知弹层内部结构。

## 状态与错误处理

- 无可切换身份时，导航栏只展示当前身份且不可点击，不渲染弹层。
- 切换期间通过 `switchingKey` 防止重复提交。
- 异常沿用轻提示“身份切换失败，请稍后重试”，并恢复可操作状态。
- 长列表在面板内容区内部滚动，关闭按钮和当前身份卡保持在可见层级。

## 验证范围

- 更新组件相关测试，覆盖弹层类型、当前身份卡、其他身份列表、加载与禁用状态。
- 回归“我的”页导航入口测试。
- 运行前端相关 Vitest、ESLint、TypeScript 检查。
- 构建 H5 与微信小程序，并在浏览器中检查面板高度、模糊效果、滚动和切换反馈。
