# 通知分发创建弹窗重构设计

## 目标

将通知分发列表页中的创建表单拆成独立、可复用的居中弹窗组件。用户点击“新建通知”后，可在一个页面内完成发送范围、接收对象和通知内容的填写；详情抽屉中的“复用内容”也使用该组件。

## 权限与发送范围

### 超级管理员

- 可选择“全平台”，向所有空间的用户发送通知。
- 可选择“指定空间”，通过可搜索的多选控件选择一个或多个空间。
- 可选择“指定用户”，通过可搜索的多选控件选择用户。

### 租户管理员

- 可选择“空间全员”，接收范围固定为当前已选空间的全部成员，不展示空间选择器，也不能触达其他空间。
- 保留“指定团队”和“指定成员”两种发送范围，并按现有接口搜索、多选目标。
- 仅当前空间所有者或超级管理员有权创建租户通知。

## 组件与数据流

- 新增 `NotificationDispatchCreateModal`，负责表单状态、范围切换、目标加载、校验和提交。
- 列表页保留权限判定、分发列表和详情抽屉；通过受控 `open`、初始内容和 `onSuccess` 向弹窗传递上下文。
- 点击“新建通知”时，按当前角色选择默认范围并清空未提交值。
- 点击“复用内容”时，预填标题、正文、分类、链接、范围和目标；若原范围不被当前角色允许，回退为该角色默认范围。
- 成功创建后关闭弹窗、提示“通知已提交，正在分发”并刷新列表。

## 单页交互与异常处理

- 弹窗保持居中显示，范围选择、按需出现的目标多选、分类、标题、正文和可选链接位于同一表单页面。
- 表单底部固定“取消”和“发送通知”按钮；提交期间禁止关闭。
- 继续使用已有目标加载重试、字段校验和仅允许站内路径或完整 HTTP(S) 链接的校验规则。
- 取消、关闭或再次点击“新建通知”均不会保留未提交内容。

## 验证

- 更新现有页面测试：覆盖两类管理员的可选范围与默认范围、范围切换后的目标查询、提交载荷、复用内容时的权限回退以及取消后的重置。
- 运行相关 Vitest 测试和 TypeScript 检查。
