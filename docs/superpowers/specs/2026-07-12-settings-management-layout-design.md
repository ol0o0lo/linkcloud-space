# 设置管理页面精简设计

## 目标

精简空间设置和团队设置中的房源发布规则展示，并让团队切换入口与页面标题保持同一视觉层级。

## 页面调整

- `PublishRulesControl` 不再显示“阻断发布 / 仅提醒 / 不校验”三枚汇总标签；保留预设按钮和逐项规则编辑表格。
- 团队设置页移除仅承载团队下拉框的独立工具栏卡片。
- 团队下拉框放置在“团队设置”标题右侧，保持当前选择、加载、切换团队和响应式宽度行为。

## 范围与兼容性

- 不调整发布规则的数据结构、预设、保存接口或恢复默认逻辑。
- 不改动空间设置的标题和分类页签行为。
- 更新空间设置、团队设置页面测试，覆盖汇总标签不再渲染及团队选择器的新位置。

## 验证

执行对应 Vitest 测试及管理端 lint / TypeScript 检查。
