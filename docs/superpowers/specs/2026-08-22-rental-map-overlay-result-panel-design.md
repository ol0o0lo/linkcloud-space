# 房源地图内嵌结果面板设计

## 目标

让房源地图占满内容区域，并将当前左侧的楼栋或小区结果列表作为地图内浮层呈现。该页面定位为轻量、专业的地图工作台：用户无需因展开列表而缩小地图可视范围，也能快速在列表和地图标记之间定位同一楼栋。

## 布局

- 顶部筛选工具栏保持不变。
- 地图卡片成为工具栏下唯一的主体区域，地图画布填满卡片。
- 楼栋结果或小区结果面板定位在地图左上角，距地图边缘 `12px`；展开时宽度沿用 `clamp(320px, 28vw, 390px)`，上下距离地图边缘均为 `12px`。
- 面板使用主题 token 提供的浅色悬浮表面、细边框和柔和阴影，不引入新的品牌色。标题区固定在顶部，列表区域独立滚动。
- 结果项按“名称 → 地址 → 套数与房态”排列；当前选中项通过主色左侧指示、浅色背景和清晰边界共同表达，不仅依赖颜色。
- 待定位楼栋以紧凑、可操作的警示入口呈现，不抢占正常结果的首屏阅读空间。
- 面板层级高于地图画布且拥有独立滚动区域；地图的缩放、拖动和右侧“适配当前结果”控件保持可用。
- 不展示地图视图级别提示，避免为高频浏览增加无关信息。

## 交互

- 展开状态沿用现有列表内容、加载、错误、空状态、待定位任务和选中项自动滚动行为。
- 展开和收起操作均在地图内部完成。
- 收起状态只显示一个 `40px × 40px` 的图标按钮，用于展开结果面板；不显示楼栋数、待定位徽标或其他文字。
- 收起状态继续持久化到现有 localStorage 键。窗口初始宽度小于 `1000px` 时默认收起。
- 展开或收起面板时，地图按面板宽度的一半水平平移，使有效可视区域的中心保持稳定。
- 点击结果项会定位至对应楼栋并展示详情气泡；点击地图标记会同步选中对应结果项并滚动到可见位置。已有选中和定位逻辑继续复用，并补足一致的视觉反馈。
- 拖动或缩放地图后，列表继续按当前视野刷新；结果被截断时保留“继续放大地图”的提示。
- 窄屏展开后的面板不超过可用高度，避免遮住关键地图区域。
- 筛选、选中楼栋、地图视口与现有数据请求逻辑不改变。

## 实现边界

- 调整范围限于 `frontend_admin/src/pages/rental/map/index.tsx` 和结果面板组件，以及为该布局与交互同步增加的最小测试。
- 复用现有 `BuildingResultPanel`、`EstateResultPanel` 和收起状态；不改接口、路由或生成的 OpenAPI 文件。
- 保留 `components.tsx` 中已有但未提交的图标和状态标签改动，只在其基础上做布局所需的最小调整。

## 验收与测试

- 展开时结果面板在地图内部浮层展示，地图不再因列表占用横向空间。
- 收起时地图内仅有展开图标按钮，点击可恢复相应结果面板。
- 小窗口初始进入页面时默认收起。
- 点击列表和地图标记后，选中状态与列表可见位置保持一致。
- 最小自动化测试验证展开、收起两种布局的定位与可访问名称，以及列表与地图标记的选中同步。
