# AppPage AI 动态背景设计

## 目标

为小程序公共页面容器 `AppPage` 增加可选的 AI 动态背景。现有页面默认外观与行为保持不变，页面只有显式指定后才启用效果。

## 组件接口

`AppPage` 新增 `aiBackground` 布尔属性：

- 类型：`boolean`
- 默认值：`false`
- 开启方式：`<AppPage ai-background>`

本次只修改 `AppPage`，不修改业务页面，也不向 `AppDetailPage`、`AppFormPage` 等封装组件透传该属性。

## 视觉效果

AI 背景固定使用蓝、紫、青配色，不跟随个人、房东或组织身份主题变化。

背景由两部分组成：

1. 覆盖页面的低对比度静态纵向渐变，保证长页面背景连续。
2. 页面顶部一屏范围内的单个伪元素，内部叠加蓝、紫、青三层半透明径向光晕，并整体缓慢漂移，形成“呼吸极光”效果。

动效应克制，不能影响卡片层级、文字对比度或列表阅读。

## 实现方式

- 仅当 `aiBackground === true` 时在 `AppPage` 根节点增加背景状态类。
- 使用 `::before` 伪元素承载动态光晕，不增加模板节点，不改变现有插槽结构。
- 伪元素使用绝对定位，限制在页面顶部一屏范围，避免改变布局尺寸。
- 伪元素设置 `pointer-events: none`，不影响点击、滚动、导航、弹窗或底部操作栏。
- 光晕使用 CSS 径向渐变生成，不使用 `filter: blur()`。
- 只保留一个约 18 秒的 `transform` 往返缓动动画，不动画背景位置或透明度。
- 页面内容保持在装饰层上方；现有导航模式主题变量继续生效。
- 使用 `prefers-reduced-motion` 媒体查询，在系统要求减少动态效果时停止动画并保留静态渐变。

## 兼容与降级

- 不依赖 Wot UI 内部类名或组件实现。
- 渐变颜色保留在 `AppPage` 的 scoped CSS 中，不新增全局主题 token，也不修改全局 `--app-bg-page`。
- 不修改 `pages.json` 的原生窗口背景色；下拉刷新和页面回弹区域继续显示原有纯色。
- 不支持 CSS 动画或媒体查询的平台仍可展示静态渐变，不影响功能。

## 验证

- 检查默认 `AppPage` 不附加 AI 背景状态类，样式保持原状。
- 检查 `ai-background` 时存在背景状态类和伪元素效果。
- 运行小程序前端现有类型检查和 lint，不新增测试文件。
- 本次不修改业务页面，因此构建后不会有现有页面默认开启该效果。
