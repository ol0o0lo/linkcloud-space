# 小程序“我的”页布局与常用操作设计

日期：2026-10-15。布局与操作清单已在设计讨论中确认，本文用于实现前的书面审阅。

## 定稿

采用 C 的资料区布局、左上角轻量身份入口和 B 的紧凑账户列表。个人资料是页面第一视觉重点，账户服务集中呈现；实名认证移入设置，首页按认证状态显示必要提示。

## 视觉与交互

- 身份入口位于导航栏左上角，使用浅色小胶囊、灰蓝图标、小字号和下拉箭头，仅展示当前身份及组织或房东名称；可点击区域至少 44px 高。
- 点击身份入口继续打开既有底部选择弹层。只有一个可用身份时，显示当前身份但不提供切换；长名称省略显示，辅助标签保留完整含义。
- 资料区突出头像、昵称和次级文案“个人资料”，整体可点击进入个人资料页。采用 C 方案的轻量背景排版，去掉原资料区的独立大卡片。
- 四个账户操作合在一张白色圆角卡片中，使用灰蓝线性图标、细分隔线和右侧箭头，不使用四宫格或独立操作卡片。
- 认证提示位于资料区下方，使用轻量文字入口，点击直接进入实名认证页，不嵌套在资料按钮内。
- 按压反馈、H5 的 Tab / Enter / Space 操作和可见焦点继续保留；沿用当前品牌颜色、角色底部导航及既有页脚行为。

## 各身份的页面顺序

| 身份 | 内容顺序 |
| --- | --- |
| 中介 | 身份入口 → 个人资料 → 必要认证提示 → 个人账户列表 |
| 租客 | 身份入口 → 个人资料 → 必要认证提示 → 找房服务 → 账户服务列表 |
| 房东 | 身份入口 → 个人资料 → 必要认证提示 → 公开店铺 → 账户服务列表 |
| 访客 | “我的”导航标题 → 登录 / 注册 → 找房服务 → 中介开通入口 |

公开店铺仍要求有效房东关系及公开店铺 key。中介开通入口保持现有展示条件：未登录或当前账号没有组织。登录后的开通入口位于该身份内容末尾；访客不显示身份切换、认证提示或账户列表。

## 常用操作与路由

| 顺序 | 显示名称 | 目标 | 内容 |
| --- | --- | --- | --- |
| 1 | 我的钱包 | `APP_ROUTES.wallet` | 余额、流水、提现 |
| 2 | 邀请好友 | `APP_ROUTES.referrals` | 邀请码、邀请链接、邀请与奖励记录 |
| 3 | 通知设置 | `APP_ROUTES.notificationPreferences` | 现有通知分类和接收渠道偏好 |
| 4 | 设置 | `APP_ROUTES.accountSettings` | 账户资料、实名认证、手机号、通知、安全及退出登录 |

邀请好友复用当前推广页面和接口，可见页面标题同步使用“邀请好友”，不新增邀请流程。通知设置作为快捷入口直达现有页面，设置页内仍保留同一入口。中介模式的分组标题为“个人账户”，其他登录身份为“账户服务”。

设置页在现有资料分组的“个人资料”后增加“实名认证”行，右侧显示当前认证状态并跳转 `APP_ROUTES.realName`。现有邮箱、手机号、通知设置、账号安全和退出登录流程保持可用。

## 实名认证状态规则

| 状态 | “我的”页提示 | 设置页状态 |
| --- | --- | --- |
| `verified` | 不显示 | 已认证 |
| `unverified` | 完善实名认证 | 未认证 |
| `pending` | 实名认证审核中 | 审核中 |
| `manual_review` | 实名认证人工复核中 | 人工复核中 |
| `rejected` | 实名认证未通过 · 查看原因 | 未通过 |
| `revoked` | 实名认证已撤销 · 重新认证 | 已撤销 |
| 其它状态值 | 认证状态未知 · 查看 | 状态未知 |

提示只表示账户状态；提交、重试及查看资料继续由已有实名认证页面决定。已认证账户始终可以通过设置进入实名认证页。

## 组件与数据边界

- `pages/me/me.vue` 负责页面组合、各身份的条件展示、常用操作跳转和轻量认证提示。
- `AppModeSwitcher.vue` 继续负责身份选项、弹层、加载和切换。仅弱化导航入口的视觉，保留当前弹层结构和选择行为。
- `pages/account/settings.vue` 增加认证状态行；`pages/account/referrals.vue` 对齐可见标题。
- 继续使用 `AppPage`、`AppCustomNavigation`、`APP_ROUTES`、现有 feature 接口与 `domain/personal-account.ts` 中的认证状态映射，不新增业务接口或生成代码。
- 身份和账号来自现有 store，认证结果来自已有个人认证接口。进入“我的”或设置时刷新认证状态；同账号刷新失败保留最近已知状态，不把失败解释成未认证。
- 切换账号后不展示旧账号的认证结果，较早完成的请求不覆盖较新的结果。身份切换失败保留原身份，沿用现有错误提示。

## 验收

1. H5 与微信小程序均符合定稿层级：身份入口弱化，头像昵称突出，账户操作使用整块列表。
2. 检查中介、租客、房东和访客的条件展示与底部导航，保留之前移除重复入口的结果。
3. 四项常用操作分别进入真实页面；邀请好友的入口与页面标题一致；设置内始终能进入实名认证。
4. 认证已通过、未认证、审核中、人工复核、未通过、撤销和未知状态的展示符合表格；状态刷新失败和账号切换不产生错误状态。
5. 检查 320px 小屏、长昵称、长身份名称、按压反馈、H5 键盘焦点和身份切换。
6. 运行相关 ESLint、类型检查、账户与路由测试、H5 及微信小程序构建；浏览器和微信真机验收分别记录。
