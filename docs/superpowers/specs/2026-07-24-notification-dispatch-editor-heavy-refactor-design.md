# 通知分发创建弹窗重度重构设计

## 目标

在不改变“新建通知”弹窗的居中单页交互、后端接口或权限结果的前提下，将当前单体编辑器按职责拆分，使权限规则、表单状态、收件人选择和消息内容可以独立理解与测试。

## 模块边界

```text
notification-dispatches/
├── CreateNotificationDispatchModal.tsx  # 弹窗壳：标题、footer、组合模块
└── editor/
    ├── policy.ts                        # 纯权限与初始值策略
    ├── types.ts                         # 编辑器共享类型
    ├── useNotificationDispatchEditor.ts # 表单、查询、提交与重置
    ├── RecipientSection.tsx             # 发送范围与接收目标
    └── MessageSection.tsx               # 分类、标题、正文与链接
```

## 职责

- `policy.ts` 维护超级管理员与租户管理员的可选范围、默认范围、历史分发内容复用时的范围回退，以及接收范围说明。函数不依赖 React 或请求层。
- `useNotificationDispatchEditor.ts` 创建和初始化表单，查询分类与目标，处理搜索、目标加载重试、链接展开、提交、关闭和成功回调。
- `RecipientSection.tsx` 只渲染范围卡片、当前空间提示和按需出现的目标多选。
- `MessageSection.tsx` 只渲染分类、标题、正文和可展开链接，并接收 hook 提供的状态与事件。
- `CreateNotificationDispatchModal.tsx` 只保留 Modal 壳、标题、footer 和两个分区的组合，不直接承载范围策略或请求细节。

## 行为约束

- 超级管理员保留全平台、指定空间、指定用户。
- 租户管理员保留当前空间全员、指定团队、指定成员；当前空间全员自动锁定当前空间，不能选择其他空间。
- 打开“新建通知”使用对应角色默认范围并清空未提交输入；复用内容会预填可访问范围，越权范围回退至默认范围。
- 保留目标搜索、失败重试、URL 安全校验、发送中禁止关闭、成功提示与列表刷新。
- 不改动 OpenAPI 生成代码、后端 API 或列表与详情抽屉的外部行为。

## 视觉设计：广播工作台

- 弹窗顶部使用蓝色渐变横幅承载发送图标、标题与副标题，替代普通 Modal 标题栏。
- 内容区域使用浅蓝灰底色；“选择接收人”和“填写消息内容”各自使用白色卡片分区。
- 发送范围保持现有 Radio 语义，但显示为图文卡片；选中项使用主色描边、浅蓝背景和图标底座。
- 接收范围说明呈现为浅蓝提示条，明确当前空间、全平台或选择目标的发送对象。
- footer 改为白色固定操作栏，发送按钮维持主色且增强视觉权重；移动端保持单列范围卡片与可滚动内容。
- 使用 Ant Design token、现有 `antd-style` 样式文件和 `prefers-reduced-motion` 约束，保证主题适配、对比度与动效可访问性。
